# Skim support

Skim is an RSS reader for the age of AI, for Mac and iPhone. This repository is where you can report a problem or ask a question.

[Open an issue](https://github.com/gm2211/skim-support/issues/new/choose). Include your device, OS version and Skim version (Settings → About, or Skim → About Skim on the Mac) if you can.
